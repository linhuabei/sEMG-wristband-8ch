# 8通道 sEMG 手环硬件设计 (V3.0)

## 项目简介
本项目是一款基于 **ESP32-S3** 和 **ADS1298** 的高精度表面肌电（sEMG）采集手环。设备集成了8通道24位生物电信号采集、6轴姿态解算（IMU）、锂电池充放电管理以及无线数据传输（WiFi/Bluetooth）功能。适用于人机交互、手势识别、康复医疗监测等场景。

 **主控芯片**：ESP32-S3-ZERO
 **模拟前端**：ADS1298IPAGR (8通道 24-bit ADC)
 **姿态传感器**：LSM6DSR (6轴 IMU)
 **设计软件**：嘉立创 EDA
 **当前版本**：V3.0 (创建: 2026-06-05, 更新: 2026-11-07)

---

## 系统架构与功能模块

系统主要分为以下几个核心模块：

1. **信号采集模块 (ADS1298)**：
   * 采用 TI 的 ADS1298，内置 8 个低噪声可编程增益放大器 (PGA) 和 8 个高分辨率 ADC。
   * 支持 8 通道差分电极输入（通过 FPC1/FPC2 接口连接电极贴片）。
2. **运动感知模块 (LSM6DSR)**：
   * 通过 IIC 总线与主控通信，提供 3 轴加速度和 3 轴陀螺仪数据，用于运动伪影消除或姿态辅助识别。
3. **电源管理模块**：
   * **充电管理**：BQ24075RGTR，支持路径管理，可通过磁吸充电口 (PCM0408-2P-C-F) 为电池充电。
   * **稳压**：TPS7A2033PDBVR LDO 提供 3.3V 系统电源（需注意模拟部分与数字部分的电源滤波）。
   * **开关控制**：SW4 控制系统总体供电。
4. **数据通信与接口**：
   * 主控通过 SPI 接口与 ADS1298 通信。
   * 预留 IIC 拓展接口和 TTL 串口，方便外接其他传感器或进行串口调试。

## 接口定义 (Pinout)

### 1. ESP32 与 ADS1298 接口 (SPI & 控制)
| ESP32-S3 引脚 | ADS1298 引脚 | 功能说明 |
| :--- | :--- | :--- |
| `GPIO2` | DOUT (Pin 28) | SPI 主入从出 (MISO) |
| `GPIO6` | SCLK (Pin 25) | SPI 时钟 |
| `GPIO7` | DIN (Pin 27) | SPI 主出从入 (MOSI) |
| `GPIO10` | CS (Pin 2) | SPI 片选信号 |
| `GPIO9` | RESET (Pin 18) | 硬件复位 (RESET#) |
| `GPIO11` | DRDY (Pin 19) | 数据就绪中断 (DRDY#，低电平有效) |
| `GPIO12` | START (Pin 14) | 转换开始控制 |
| `GPIO13` | PWDN (Pin 17) | 掉电/待机控制 (PWDN#) |

### 2. 传感器与扩展接口 (IIC)
| ESP32-S3 引脚 | 器件/接口 | 功能说明 |
| :--- | :--- | :--- |
| `GPIO1` | LSM6DSR | IMU IIC_SDA |
| `GPIO3` | LSM6DSR | IMU IIC_SCL |
| `GPIO4` | 外部扩展接口 | 扩展 IIC_SCL |
| `GPIO5` | 外部扩展接口 | 扩展 IIC_SDA |

### 3. 其他控制与外部接口
| ESP32-S3 引脚 | 器件/接口 | 功能说明 |
| :--- | :--- | :--- |
| `GPIO8` | 状态灯 | MCU 状态指示灯 |
| - | 磁吸充电口 (U14) | `PCM0408-2P-C-F` (VBUS, GND) |
| - | 电池接口 (U13) | `BX-ZH1.5-2PWT` (BAT+, BAT-) |
| - | IIC 扩展口 (U12) | `HC-FPC-0.5-4P-CH20` (VCC, GND, SCL, SDA) |

| - | 电极接口 | 2 个 10 Pin FPC 接口 (FPC1, FPC2)，支持 8 个差分通道 (IN1N/P - IN8N/P) |

## 电源说明
* **输入电压**：5V (磁吸充电口)
* **电池电压**：3.7V 锂电池
* **充电电流**：由 BQ24075 的 ISET 引脚电阻 (R55 = 1.78kΩ) 决定。
* **系统电压**：3.3V (由 TPS7A2033 提供)。注意：由于是微弱生物电信号采集，请注意 AVDD 和 DVDD 的隔离及退耦电容（C59, C60 等）。

## 调试与使用注意事项 (Tips)

1. **电极连接**：连接 FPC 柔性排线时，请务必保证断电操作，防止静电 (ESD) 击穿 ADS1298 模拟前端。
2. **时钟配置**：ADS1298 默认使用内部时钟，若需更高精度，请检查 CLK 引脚外接晶振（当前图纸留有外围电容，默认可能走内部）。
3. **抗干扰设计**：
   * 贴片电极的走线应尽量短且等长。
   * 测试时请远离强电磁干扰源（如大功率电机、高频无线发射设备）。
4. **状态指示灯**：板载 `LED1` 和 `LED4` 用于指示电源和系统状态（MCU 状态灯由 GPIO8 控制）。

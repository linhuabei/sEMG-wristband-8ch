# 自采数据集接入规范（连续识别版）

> 目的：让"你们采的数据"能直接跑进现有管线，并且**结构上就满足投稿要求**。
> 代码入口：`src/custom_dataset.py`（已自测通过），训练命令见文末。

---

## 一、先定三件事（决定论文能不能成立）

### 1. 连续标签（参考标准）从哪来 —— 这一步决定精度上限

| 方案 | 成本 | 角度精度 | 优点 | 风险 |
| --- | --- | --- | --- | --- |
| 商用数据手套（VRTRIX / CyberGlove） | ¥5k–10 万 | 高，厂商标定 | 省事、可引用 | 贵；与肌电的时间同步要自己做 |
| 自制弯曲传感器手套（flex / 柔性拉伸） | ¥几百 | 中，需自己标定 | 便宜、可复现 | 非线性、蠕变、每次戴脱要重标 |
| 视觉动捕（MediaPipe Hands / 双目相机） | ≈0 | 中（±5° 量级） | 便宜、非接触 | 遮挡、光照、帧率；**与肌电同步要用同步标记** |
| IMU 指套 | ¥几十/指 | 中（积分漂移） | 便宜 | 角度漂移，需姿态解算 |
| 固定夹具 + 角度传感器/电位器 | 低 | 很高 | 精度最好 | 只能做固定轨迹动作，动作集受限 |

**建议**：先做**同步与精度验证实验**（同一段动作，用两套参考同时采，比较一致性），
把"参考标准本身的误差"写进论文——这是连续识别论文最常被质疑的地方。

### 2. 动作集怎么选

* **静态姿态**（保持某个手势 5 s）：好标定、结果漂亮，但"连续"的味道不足；
* **动态连续动作**（握-开-捏循环、腕屈伸扫动、手指逐个屈伸）：更贴合"连续控制"的卖点；
* **推荐混合**：6 个静态姿态（对齐公开数据集便于对比）+ 3–4 个动态轨迹（体现连续解码价值）。

### 3. 受试者与重复设计

| 项目 | 建议 | 为什么 |
| --- | --- | --- |
| 人数 | **12–20 名**健康受试者 | 三区论文一般 ≥10；跨人实验需要更多 |
| 每人重复 | 每个动作 **6 次** | 与 NinaPro 一致，划分 1/3/4 训练、6 验证、2/5 测试 |
| 戴脱次数 | **至少 2 次**（中间取下再戴） | 支撑"跨会话/重新佩戴"实验，这是真实使用场景 |
| 采样率 | 1000–2000 Hz（与设备一致） | 与公开数据集可比；窗口 100 ms = 100/200 点 |
| 每段时长 | 动作 5 s + 休息 3 s | 同 NinaPro，便于横向对比 |

## 二、采集流程模板（照这个做就能写进论文的"实验设置"）

1. **电极定位**：用定位卡/记号笔固定 8 个电极位置，拍照留存，记录极间距与参考电极位置；
2. **皮肤处理**：酒精擦拭，静置 2 分钟；
3. **静息基线**：采集 30 s 完全放松（用于噪声/基线与标准化统计）；
4. **最大自主收缩（MVC）**：每个动作 3 s × 3 次，用于幅度归一化与疲劳监控；
5. **正式采集**：按动作顺序（**每次重复内随机化**，避免顺序效应），动作 5 s + 休息 3 s；
6. **同步标记**：动作开始/结束打同步脉冲（按键/光闪/TTL 均可），用于事后对齐校验；
7. **疲劳控制**：每 5 分钟休息 1 分钟，记录时间戳；
8. **戴脱重复**：取下电极、重新定位、重复步骤 3–6；
9. **每次采完立刻跑质检**（见第四节）。

## 三、文件格式（`custom_dataset.py` 直接读这个）

每条记录一个 `.npz`（或同名 `.csv`），**命名建议 `S01_ses1.npz`**（`S01` 里能解析出受试者号）。

| 字段 | 形状 | 必填 | 说明 |
| --- | --- | --- | --- |
| `emg` | (T, 8) float32 | ✅ | 8 通道原始肌电（单位随意，程序会标准化） |
| `fs` | 标量 int | ✅ | 采样率，如 2000 |
| `trial` | (T,) int16 | ✅ | **第几次重复**（1…6），用于划分训练/验证/测试 |
| `label` | (T,) int16 | ✅ | 动作编号，0 = 休息，-1 = 不计入 |
| `angles` | (T, K) float32 | 连续识别必填 | 参考关节角（度） |
| `angle_names` | (K,) str | 建议 | 如 `["食指MCP","食指PIP",...]` |
| `subject` / `session` | 标量 | 建议 | 受试者号 / 第几次戴脱 |
| `sync` | (T,) 0/1 | 建议 | 同步标记通道，用于核对时间对齐 |

CSV 版本：表头用 `ch1…ch8`、`ang1…angK`、`trial`、`label`，同样能读。

**硬性要求**：肌电与参考角度必须是**同一时钟**采的；如果做不到，就用 `sync` 通道事后对齐，
并报告对齐后的残余误差（建议 ≤10 ms）。

## 四、采集后质检清单（每次采完跑，问题当场重采）

| 检查项 | 判据 | 不通过怎么办 |
| --- | --- | --- |
| 通道脱落/饱和 | 单通道 RMS 偏离同受试者中位数 4 倍以上，或近似常数 | 重新贴电极 |
| 工频干扰 | 50 Hz 及其谐波功率占比过高 | 检查接地/参考电极 |
| 标签-肌电对齐 | 动作指示与肌电包络的互相关峰值落在 0±10 ms | 检查同步标记 |
| 参考角度范围 | 无跳变、无超量程、无长时间不变化 | 检查手套/标记点 |
| 时长与重复 | 每个动作 ≥5 s、重复次数 = 6 | 补采 |
| 静息基线 | 基线 RMS 稳定、无漂移 | 重新静置 |

## 五、跑进现有管线

```bash
cd 算法/src

# 1) 先自测（不需要真实数据，验证环境）
python custom_dataset.py --self-test

# 2) 连续关节角（回归）
python train.py --dataset custom --data-dir "D:/自己的数据" \
                --mode per-subject --subjects 1-12 --task angles \
                --epochs 40 --patience 8 --norm-window 30

# 3) 离散手势（分类，可选）
python train.py --dataset custom --data-dir "D:/自己的数据" \
                --mode per-subject --subjects 1-12 --task gesture

# 4) 画图 / 导出插件
python evaluate.py --run ../outputs/数据目录名
python export_numpy.py --ckpt ../outputs/数据目录名/best.pt --copy-to-plugin angle
```

换数据不用改任何代码，只要满足第三节的字段要求。

## 六、论文里应该出现的实验（对照表，供组会讨论）

| 实验 | 目的 | 需要的表/图 |
| --- | --- | --- |
| 硬件表征 | 输入折合噪声 µVrms、CMRR dB、带宽、串扰、BLE 丢包/抖动、端到端延迟 | 一张指标表 + 与商用设备同肌肉对比 |
| 参考标准一致性 | 证明连续标签本身可信 | 一致性散点图 + 残差直方图 |
| 算法对比 | TD+LDA/SVR、CNN、LSTM、TCN、CNN-Transformer | R²/CC/MAE + 参数量 + 单帧延迟 |
| 消融 | 去注意力、去滚动标准化、去目标低通、窗口长度 | 逐项 ΔR² |
| 通道精简 | 8 通道 → 6/4/2 通道精度损失 | 精度-通道数曲线（对可穿戴是卖点） |
| 跨人/跨会话 | 新用户、重新佩戴后的性能 | 每人 R² 分布 + 需要的校准时长 |
| 实时回放 | 端到端延迟与跟踪曲线 | 延迟直方图 + 真实 vs 预测轨迹 |

## 1. 模型是干什么的

输入：**8 通道表面肌电（sEMG）在 100 ms 窗口内的波形**（200 个采样点 @ 2 kHz）。

输出两种形态，由同一个主干网络换头实现：

| 形态 | 输出 | 用途 | 损失函数 |
| --- | --- | --- | --- |
| **离散分类** | 7 类（上位的 6 种手势 + 休息）或 18 类（NinaPro 17 动作 + 休息）的概率 | 认手势 | 交叉熵 |
| **连续回归** | 21 路关节角（Cyberglove 22 路去掉第 20 路） | 手指/手腕连续跟随 | 均方误差 |
| **多任务** | 上面两个同时输出 | 分类辅助 + 连续解码 | 交叉熵 + λ·MSE |

一句话：**"看 0.1 秒的 8 路肌电波形，判断手在做什么"**——只有 8 万个参数，
推理时不需要 GPU，也不需要 PyTorch。

## 2. 送进模型之前，数据被处理成什么样

| 步骤 | 参数 | 说明 |
| --- | --- | --- |
| 通道选择 | 取 DB2 的 sEMG 第 1–8 路 | 与手环的 8 个电极对应 |
| 带通滤波 | 20–450 Hz（4 阶巴特沃斯） | 去基线漂移与高频噪声 |
| 工频陷波 | 50 Hz（Q=30） | 去电网干扰 |
| 直流阻断 | 一阶 IIR | 去电极极化漂移 |
| 标准化 | 逐通道 z-score，**因果滚动 30 s** | 消除个体幅度差异；只用"当前及过去"的数据，可实时 |
| 滑窗 | 窗长 200 点（100 ms）；训练步长 200、测试步长 50（25 ms） | 测试时窗口重叠 75%，输出更平滑 |
| 关节角目标 | 5 Hz 低通 + 取窗口末 25 ms 均值 | 去手套高频抖动；减少输出滞后 |
| 划分 | 训练=第 1/3/4 次重复，验证=第 6 次，测试=第 2/5 次 | 按整段重复划分，杜绝重叠窗口泄漏 |

> ⚠️ 关键工程约束：**训练端与部署端必须用同一套"因果"预处理**。
> 用离线零相位滤波训练、再接到上位机实时链路，模型准确率会从 0.78 掉到 0.59、
> "仅动作样本"从 0.51 掉到 0.02（见 `check_online_pipeline.py` 的实测）。

## 3. 结构逐层详解

记批大小为 $B$，输入张量 $x \in \mathbb{R}^{B \times 8 \times 200}$。

| # | 层 | 操作与公式 | 输出形状 | 参数量 |
| --- | --- | --- | --- | --- |
| 0 | 输入 | 8 通道 × 200 点 | (B, 8, 200) | 0 |
| 1 | 卷积 1 | $h_o[t]=\sum_{c=1}^{8}\sum_{k=0}^{4} W_{o,c,k}\,x_{c,\,t+k-2}$（k=5, pad=2, 无偏置） | (B, 32, 200) | 32×8×5 = 1,280 |
| 2 | 批归一化 + ReLU | $\hat y=\gamma\frac{y-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta$，再 $\max(0,\cdot)$ | (B, 32, 200) | 64 |
| 3 | 最大池化 | 相邻 2 点取最大 | (B, 32, 100) | 0 |
| 4 | 卷积 2 | 同上，32→64 通道 | (B, 64, 100) | 64×32×5 = 10,240 |
| 5 | 批归一化 + ReLU | 同上 | (B, 64, 100) | 128 |
| 6 | 最大池化 | 相邻 2 点取最大 | (B, 64, 50) | 0 |
| 7 | 转置 | 变成 (B, 时间, 特征) | (B, 50, 64) | 0 |
| 8 | 位置编码 | $PE(t,2i)=\sin\!\big(\tfrac{t}{10000^{2i/64}}\big)$，$PE(t,2i{+}1)=\cos(\cdot)$（固定，不训练） | (B, 50, 64) | 0（缓冲区 3,200 个常数） |
| 9 | 编码器 × 2 层 | 见下方公式 ①–④ | (B, 50, 64) | 每层 33,728，共 67,456 |
| 10 | 层归一化 | LayerNorm(64) | (B, 50, 64) | 128 |
| 11 | 全局平均池化 | $z=\frac{1}{50}\sum_{t=1}^{50} h_t$ | (B, 64) | 0 |
| 12 | Dropout | 训练时随机置零 20% | (B, 64) | 0 |
| 13 | 分类头 | $\text{logits}=W_c z+b_c$ → Softmax | (B, 7) 或 (B, 18) | 64×7+7=455（7 类） |
| 14 | 回归头 | $a=W_a z+b_a$ | (B, 21) | 64×21+21=1,365 |

**编码器每层的四步**（Pre-LN + 残差）：

$$
\begin{aligned}
&\text{① }q,k,v = W_q\,\mathrm{LN}(h),\; W_k\,\mathrm{LN}(h),\; W_v\,\mathrm{LN}(h)
   &&\text{（8 头，每个头 } d_h=8\text{）}\\
&\text{② }h \leftarrow h + W_O\!\left[\mathrm{softmax}\!\left(\frac{qk^{\top}}{\sqrt{d_h}}\right)v\right]
   &&\text{（多头拼接后再投影）}\\
&\text{③ }h \leftarrow h + W_2\,\mathrm{GELU}\!\big(W_1\,\mathrm{GELU}(\mathrm{DWConv}_3(h'))\big),\; h'=\mathrm{LN}(h)
   &&\text{（深度可分离卷积前馈，64→128→64）}\\
&\text{④ }\text{每步都带残差与 LayerNorm}
\end{aligned}
$$

**全模型可训练参数**：

| 模型 | 参数量 | 权重文件大小 |
| --- | --- | --- |
| 7 类手势（上位机用） | **79,751** | ≈ 312 KB |
| 18 类手势 | 80,466 | ≈ 314 KB |
| 18 类 + 21 路角度（多任务） | **81,831** | ≈ 320 KB |

## 4. 为什么这样设计（每条都有实测依据）

| 设计 | 理由 | 我们的实测证据 |
| --- | --- | --- |
| 1D 卷积（k=5, 2.5 ms 感受野） | 肌电的判别信息大量存在于"局部波形形状/爆发点" | 打印出的第一层卷积核里既有"低通/平滑型"（如 `[0.207 0.248 0.219 0.000 -0.075]`），也有"差分/高通型"（如 `[-0.084 0.046 0.015 -0.066 0.011]`），见 `trace_one_window.py` |
| 最大池化两次（200→50） | 降低时间分辨率、增强小位移不变性、减少注意力计算量 | — |
| 自注意力（8 头） | 建模**跨通道、跨时刻**的肌群协同，CNN 感受野覆盖不到 | 依据来自结构分析；**"去掉注意力"的消融本项目尚未做，已列入下一步**（现有消融：预处理一致性、多任务 vs 纯回归、窗口长度、类别加权） |
| 深度可分离卷积前馈 | 同样做"升维→非线性→降维"，但用深度卷积替代一半全连接，为嵌入式留余地 | 每层前馈 **16,832** 个参数（若用标准 4 倍全连接前馈需 33,088，省掉约一半） |
| Pre-LN + 残差 | 深层稳定训练；小数据下不易发散 | — |
| 全局平均池化 | 输出与序列长度无关；对时间偏移更鲁棒 | — |
| Dropout 0.2 | 抑制小数据过拟合 | — |
| 纯回归（w_gesture=0） | 分类损失会与回归任务争抢容量 | 多任务 R² 0.332 → **纯回归 0.502** |
| 训练/部署同链路预处理 | 避免域偏移 | 离线训练 0.777 → 实机链路 **0.585**（"仅动作" 0.51 → 0.02） |
| 通道重排增强 **关闭** | 8 通道对应具体电极，打乱会破坏空间信息 | 打开时收敛明显变慢、精度更低 |
| 窗口 100 ms（而非 200 ms） | 时间分辨率与算力平衡 | 200 ms 窗口 R² 0.476 < 100 ms 的 0.502 |

## 5. 训练细节

| 项目 | 设置 |
| --- | --- |
| 损失（分类） | 交叉熵 + 标签平滑 0.02（防止过度自信） |
| 损失（回归） | 标准化关节角上的 MSE |
| 损失（多任务） | $L = w_g\cdot$CE $+ w_a\cdot$MSE，默认 $w_g=1, w_a=0.5$ |
| 类别不平衡 | 可选 `balanced` 类别权重（休息类占 50–78%） |
| 优化器 | AdamW，lr = 1×10⁻³，权重衰减 1×10⁻⁴ |
| 批大小 / 轮数 | 128 / 30–40 轮（早停耐心 6–8 轮） |
| 学习率调度 | 余弦退火 $\eta_t=\eta_{\min}+\frac{1}{2}(\eta_{\max}-\eta_{\min})(1+\cos\frac{\pi t}{T})$ |
| 梯度裁剪 | 范数上限 5.0 |
| 数据增强 | 10–30 dB **信噪比**高斯白噪声、时间轴翻转（通道重排默认关闭） |
| 模型选择 | 分类按验证准确率 / 宏平均 F1；回归按验证 R² |
| 微调（个人化） | 冻结卷积前端，只训 Transformer 与输出头，lr = 2×10⁻⁴，16 轮；再用本人验证集拟合逐通道仿射校准 |
| 随机种子 | 42（同一条命令可复现） |

## 6. 实测性能（NinaPro DB2，8 通道）

**离散手势**

| 任务 | 汇总准确率 | 宏平均 F1 | 平衡准确率 | 仅动作样本 |
| --- | --- | --- | --- | --- |
| 7 类（上位机 6 手势 + 休息，8 人） | **0.7166** | 0.5541 | 0.6783 | **0.6671** |
| 18 类（NinaPro 全动作，8 人） | 0.6735 | 0.4950 | 0.4715 | 0.4470 |

逐受试者（7 类）：0.708 ± 0.095（最低 0.581，最高 **0.859**）；
各类召回：握拳 0.777、比大拇指 0.725、十指张开 0.665、比耶 0.659、捏合 0.627、OK 0.560。

**连续关节角（4 人，每人一个模型）**

| 指标 | 数值 |
| --- | --- |
| 关节角 R² | **0.471** |
| 逐通道平均皮尔逊 r | **0.680** |
| MAE（按 0~90° 显示口径） | **7.64°** |

逐人：S1 0.502 / S2 0.431 / S3 0.552 / S4 0.398；
逐通道：手指屈伸类 r≈0.80，前臂旋前/旋后类 r≈0.50。

**消融与对照**

| 配置 | 结果 |
| --- | --- |
| 逐受试者模型 vs 跨受试者统一模型 | 0.717 vs 0.677（7 类口径） |
| 多任务（分类+回归） vs 纯回归 | R² 0.332 vs **0.502** |
| 离线预处理 vs 上位机一致预处理 | 离线好看，但实机掉一半（见第 2 节） |
| 窗口 100 ms vs 200 ms | 0.502 vs 0.476 |
| 免手套伪标签迁移 vs 真标签迁移 | R² −0.206 → **+0.158**（恢复真标签方案 81% 的增益） |

## 7. 可解释性：模型在看哪里

用**梯度归因**（$\left|\partial y/\partial x\right|$ 对测试集平均）和**遮挡实验**两条独立路径交叉验证：

| 结论 | 数值 |
| --- | --- |
| 通道重要性（7 类手势） | **CH1 > CH5 > CH6 > CH8 > …**，去掉 CH1/5/6 时"仅动作"准确率掉 20 个百分点以上 |
| 时间分布（7 类） | 窗口前段最敏感（0–10 ms 占 13.6%） |
| 时间分布（连续角度） | 呈中间高、两端低，**30–60 ms 占 32.8%** |

即：分类更依赖"波形细节"，连续回归更依赖"窗口中部（≈当前时刻前 20–70 ms）的肌电"。
（注意：敏感度反映"模型依赖"，不等于解剖学上的肌肉贡献。）

## 8. 推理与部署

| 环节 | 做法 |
| --- | --- |
| 推理引擎 | `numpy_infer.py`：把 PyTorch 权重导出成 `.npz`，用纯 NumPy 前向；与 PyTorch 数值误差 < 1×10⁻⁶ |
| 依赖 | 只需要 NumPy（上位机 `.venv` 不装 PyTorch） |
| 节拍 | 上位机每 50 ms 给一块数据；插件攒够 100 ms（2 块）推理一次 |
| 采样率自适应 | 2 kHz 直接用；1 kHz 时线性重采样到 200 点 |
| 标准化 | 最近 30 s 的滚动均值和标准差（与训练一致） |
| 输出平滑 | 后验概率 / 角度做指数平滑（系数 0.5），抑制跳变 |
| 个体校准 | 训练时用验证集拟合逐通道仿射 $y\approx a\hat y+b$，参数存进权重文件，推理时自动应用 |
| 体积 | 45–47 个张量、约 320 KB |

## 9. 局限与改进方向

1. **电极布置不同**：NinaPro 是"前臂一圈 8 电极"，本项目手环贴在特定肌肉上，通道语义不完全等价 → 用自采数据微调后可用；
2. **个体差异**：跨受试者统一模型明显弱于逐人模型（0.677 vs 0.717）→ 已实现"免手套伪标签迁移"（R² −0.206 → +0.158）；
3. **关节角未标定**：Cyberglove 是无量纲原始值，MAE 的绝对值仅供参考；
4. **精度上限**：本文只用了 3 次重复训练、8 通道、8 万参数的小模型；更大模型 + 更多重复 + 交叉验证可望接近文献水平（同数据集 12 通道、时域特征 + 分类器约 75–85%）；
5. **嵌入式部署**：尚未做 INT8 量化与剪枝；参数量虽小（8 万），但注意力算子在 MCU 上需专门优化。

# 8 通道 sEMG 手势识别算法（CNN-Transformer）

配套 **sEMG-wristband-8ch** 八通道肌电手环的算法子项目：用 NinaPro DB2 公开数据集做离线训练与评估，并把模型导出成纯 NumPy 插件，供上位机直接导入。

> **状态说明**：这是一个研究/课程项目的算法原型，不是生产系统，也不是医疗设备。
> 下面的数字全部来自 NinaPro DB2 的**离线、逐人**实验，不等于真实手环佩戴、跨用户或长期使用的效果。
> 真实硬件数据和跨人泛化都还没有充分验证。

## 包含

- `src/`：数据读取、预处理、滑窗切分、CNN-Transformer 训练/评估、权重导出、个人化微调、划分审计与分析脚本；
- `plugins/`：上位机可直接导入的手势/连续角度插件，纯 NumPy 推理引擎，以及 `.npz` 权重；
- `outputs/`：只保留模型结构图、逐层表和汇总表；完整训练输出未包含；
- 文档：模型说明、免手套用户迁移实验、自采数据接入规范。


## 结果（请连同条件一起看）

统一条件：NinaPro DB2、sEMG 1–8 通道、100 ms 窗口（200 点 @2 kHz）、每人单独训练、按整段重复划分（训练 1/3/4、验证 6、测试 2/5）、排除 20 号受试者。

| 任务 | 设置 | 指标 |
| --- | --- | --- |
| 7 类上位机手势 | 8 人，逐人模型 | 总体准确率 **0.717**；逐人 **0.708 ± 0.095**（0.581–0.859）；仅动作样本 **0.667** |
| 18 类 NinaPro 动作 | 8 人，逐人模型 | 总体准确率 **0.674**；仅动作样本 **0.447** |
| 连续关节角 | 4 人，逐人纯回归 | R² **0.471**；平均 r **0.680**；MAE **7.6°**（显示口径，不是真实角度误差） |
| 跨人模拟（S3→S2） | 公开数据集模拟 | 直接迁移 R² **−0.206**；本人数据微调后 **+0.242**（仅一次模拟） |

> 这些是离线实验结果，不是实时佩戴实测。测试集里休息样本接近一半，所以“总体准确率”会被抬高；“仅动作样本准确率”更能反映动作本身的难度。

> 实际上由于transformer需要大量的数据量其结果在小数据量里存在一定偏差

## 使用操作

### 1. 在上位机里使用插件（只需要 NumPy）

1. 打开上位机 → **用户迁移 → 实时识别与迁移** → 「导入算法 .py」；
2. 选择 `plugins/手势识别_CNNTransformer.py`；
3. 确认同一目录下还有 `推理引擎_纯NumPy.py` 和 `模型权重_手势.npz`；
4. 连接手环开始采集，前约 1.7 s 插件在攒数据，之后按 50 ms 节拍输出。

连续关节角：选择 `plugins/连续关节角_CNNTransformer.py`，配套 `模型权重_连续关节角.npz`。

> 插件接口只认 `NAME`、`TYPE`、`predict(ctx)` 三个名字；插件文件本身可以是中文名。

### 2. 训练 / 复现（需要 PyTorch）

先把 NinaPro DB2 放到 `公开数据集/Ninapro/DB2`（本仓库不包含数据），然后：

```bash
pip install -r requirements.txt
cd src
python train.py --mode per-subject --subjects 1-8 --epochs 30 --norm-window 30
python evaluate.py --run ../outputs/ex1_persubject_gesture --per-class-table
python export_numpy.py --ckpt ../outputs/ex1_persubject_gesture/best.pt --copy-to-plugin gesture
```

常用参数：

- `--label-mode app6`：只保留能对上上位机 6 种手势的动作（7 类）；
- `--mode pooled`：所有人一起训一个通用模型（跨人，精度会低一些）；
- `--multi-task`：同时回归 Cyberglove 关节角。

完整命令和实验设置见 [docs/技术细节.md](docs/技术细节.md)。

## 已知限制
- 离线、逐人、NinaPro DB2 上评估；未在真实手环上做闭环测试
- 测试集休息样本接近一半，总体准确率偏高
- 跨人仅一次 S3→S2 模拟，不足以支撑泛化结论
- Transformer 在小样本逐人设置下方差偏大
- 连续角度 MAE 为归一化空间口径，非真实角度误差

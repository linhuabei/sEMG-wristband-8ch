# 实验报告：基于共享运动学先验的"免手套"用户迁移

> 版本：2026-09-11 | 数据集：NinaPro DB2（公开数据集） | 代码：`算法/src/`
> 完整复现命令见第 8 节；所有数字均来自本仓库脚本的实际运行结果。

---

## 1. 摘要

表面肌电（sEMG）连续解码模型存在严重的**个体差异**问题：在 A 身上训练的模型，
直接用于 B 时性能会崩掉。常规解法是让新用户佩戴**数据手套**采集带角度标签的数据再微调，
但手套昂贵、佩戴麻烦，是产品化的主要障碍。

本报告提出并实验验证了一种**免手套的用户迁移**方案：利用"同一个人做某个动作时关节角的
变化轨迹在人群中相似"这一先验，用**其他受试者的平均动作模板**为新用户生成**伪标签**，
再进行轻量微调。在 NinaPro DB2 上的实验结果是：

| 设置 | 关节角 R² | 平均 r | MAE |
| --- | --- | --- | --- |
| 不迁移（通用模型直接用，已含自适应标准化） | −0.206 | 0.230 | 12.19° |
| **免手套迁移（模板伪标签 + 微调）** | **+0.158** | 0.399 | 10.54° |
| 有手套迁移（真标签 + 微调） | +0.242 | 0.481 | 9.85° |
| 目标用户从头训练（性能上限参考） | +0.431 | 0.653 | 8.36° |

**免手套方案恢复了真标签方案约 81% 的性能增益**（R² 增益 0.364 / 0.448），
且采集时**只需要知道"什么时候在做哪个动作"**——这正是上位机本来就记录的标签，
因此设备侧不需要任何额外硬件。

---

## 2. 背景与问题

### 2.1 为什么需要用户迁移

sEMG 的幅值、频谱与通道间模式同时受**肌肉构型、皮下脂肪、电极位置与接触阻抗**影响，
个体差异很大。实测（同一套 8 通道模型，测试集为第 2/5 次重复）：

* 同一人从零训练：R² = 0.431（可用）
* 换成另一个人直接使用：R² = −0.206（**比"永远输出平均值"还差**）

### 2.2 现有做法的门槛

主流做法是"新用户戴手套采一段数据 → 有监督微调"，这要求：
参考角度设备（数据手套 / 动捕）+ 与肌电的精确时间同步 + 额外操作流程。
对低成本可穿戴设备而言，这三条都是负担。

### 2.3 本文的问题

> 能否**不用任何参考角度设备**，只靠"用户按提示做几个规定动作"，
> 就完成用户迁移、拿到大部分的性能增益？

---

## 3. 方法

### 3.1 总体流程

```
① 构建模板库（一次性，离线）
      用已有的多位受试者数据，为每个动作求"平均关节角轨迹模板"
        ↓
② 新用户采集（只做规定动作，不需要手套）
      上位机按提示让用户做 6 个标准动作 × 6 轮，记录 8 通道肌电 + 动作编号
        ↓
③ 生成伪标签
      按"动作编号切换处"切段；每段用该动作模板按时间拉伸填进去；
      休息段填"静息姿态"模板
        ↓
④ 轻量微调
      冻结卷积前端，只训练 Transformer 与输出头（小学习率、早停）
        ↓
⑤ 重新校准 + 部署
      用该用户的验证集拟合逐通道仿射校准；导出权重，覆盖上位机插件里的 .npz
```

### 3.2 先检验假设：跨人运动学到底有多相似

对 8 位受试者（每人 17 个动作 × 6 次重复），把每段动作裁掉首尾过渡、
时间归一化到 100 点后比较（逐通道相关系数再平均）：

| 比较对象 | 相关系数 | 含义 |
| --- | --- | --- |
| 同一人、不同重复（组内上限） | 0.515 ± 0.283 (n=2040) | 连本人两次都不完全一致 |
| 不同人、同一动作的**保持姿态** | **0.787 ± 0.419 (n=476)** | **静态姿态高度共享** |
| 不同人、同一动作的**整段轨迹** | 0.205 ± 0.226 (n=476) | 动态过程差异明显 |
| 不同动作（对照下限） | 0.025 ± 0.196 (n=8704) | 说明 0.205 不是噪声 |
| 同一姿态的绝对幅度跨人变异系数 | 2.517 | 个体幅度差异极大 |

**结论**：姿态（也就是"起止手势"）是共享的，这为伪标签提供了锚点；
但轨迹时序与绝对幅度是个体化的，因此伪标签**只能是"形状大致正确"的中等质量标签**，
这决定了本方法的精度上限。

逐动作的跨人一致性（越高越"通用"）：

| 动作 | 7 食指伸出 | 6 握拳 | 5 五指张开 | 2 食指中指伸 | 16 尺偏 | 14 腕伸 | … | 9 旋后 | 13 腕屈 | 17 握拳腕伸 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 相关 | 0.370 | 0.312 | 0.273 | 0.232 | 0.228 | 0.226 | … | 0.116 | 0.101 | 0.098 |

→ **采集协议应优先选手指/握力类动作**（一致性 0.2~0.37），避免前臂旋前旋后（≈0.10）。

### 3.3 模板库

对每个动作 m，把**供体受试者**的全部重复轨迹（时间归一化到 100 点）逐点平均，得到
模板 `T_m ∈ R^{21×100}`；同时保存静息姿态（供体休息段均值）与全局幅度统计量。

### 3.4 伪标签生成

对新用户的记录：

* 按 `label` 的连续段切分（上位机记录动作编号，切分免费得到）；
* 每段长度为 L，把 `T_m` 线性重采样到 L，直接作为该段的角度标签；
* `label = 0` 的段填静息姿态；
* 不做个体幅度缩放（无真值时无法标定，这是本方法的主要误差来源）。

### 3.5 微调策略

* **冻结卷积前端**（conv1/conv2/BN），只更新 Transformer 与输出头——小数据下抑制过拟合；
* AdamW，lr = 2×10⁻⁴，batch = 64，余弦退火，16 轮，验证集早停（patience=6）；
* 目标为标准化后的 21 路关节角（MSE）；
* 微调后用**该用户的验证集**拟合逐通道仿射校准 `y ≈ a·ŷ + b`（不接触测试集）。

## 4. 实验设置

| 项目 | 设置 |
| --- | --- |
| 数据 | NinaPro DB2 练习 B（17 动作 × 6 次重复）；8 通道 sEMG，2 kHz；21 路 Cyberglove 关节角（22 路排除第 20 路） |
| 窗口 | 长 200 点（100 ms）；训练/验证步长 200，测试步长 50（25 ms） |
| 划分 | 重复 1/3/4 训练、6 验证、2/5 测试（按整段重复划分，杜绝重叠窗口泄漏） |
| 预处理 | 与上位机一致的因果滤波（20–450 Hz 带通 + 50 Hz 陷波 + 直流阻断）+ 30 s 因果滚动标准化；角度目标 5 Hz 低通、取窗口末 25 ms |
| 基线模型 | 受试者 **S3** 的逐人模型（40 轮训练，其测试集 R² = 0.552） |
| 目标用户 | **S2**（该模型从未见过其数据） |
| 模板供体 | **S1 / S4 / S5 / S6**（与目标用户、与基线模型作者均不重合） |
| 评估 | 目标用户测试集（第 2/5 次重复，12099 个窗口）上的 R²、逐通道平均 r、MAE |

对照组设计：

| 代号 | 说明 |
| --- | --- |
| A | 通用模型直接用（含插件的滚动标准化自适应） |
| B | A + 旧用户的仿射校准（检验"免训练校准"是否够用） |
| C | **伪标签微调**（本方法，不使用任何真角度） |
| D | 真标签微调（有手套，作为方法上界之一） |
| E | 目标用户从头训练（性能上界参考） |

## 5. 结果

### 5.1 主结果

| 代号 | 方案 | R² | 平均 r | MAE | 相对 A 的增益 |
| --- | --- | --- | --- | --- | --- |
| A | 通用模型直接用 | −0.206 | 0.230 | 12.19° | — |
| B | A + 旧用户仿射校准 | −0.170 | 0.230 | ~12.2° | +0.036（几乎无用） |
| **C** | **伪标签微调（免手套）** | **+0.158** | **0.399** | **10.54°** | **+0.364** |
| D | 真标签微调（有手套） | +0.242 | 0.481 | 9.85° | +0.448 |
| E | 目标用户从头训练 | +0.431 | 0.653 | 8.36° | +0.637 |

**关键结论**

1. **免训练的自适应救不回来**（A→B 只提升 0.036）：仅靠滚动标准化与旧校准，
   跨用户 R² 仍为负值，说明必须更新网络权重；
2. **免手套方案可用**（C）：R² 从 −0.206 提升到 +0.158，恢复了真标签方案 **81%** 的增益；
3. 距离"从零训练"（E）仍有差距（0.158 vs 0.431），差距主要来自
   **伪标签的个体幅度误差**与**轨迹时序差异**（见 3.2 节）。

### 5.2 伪标签本身的质量

| 指标 | 数值 |
| --- | --- |
| 伪标签与真标签的逐通道平均相关 | 0.604 |
| 伪标签与真标签的 RMSE（手套原始单位） | 41.7 |

伪标签只是"中等质量"，但微调依然有效——**因为微调真正学习的是"这个人的肌电→姿态映射"，
标签只需要提供大致正确的形状**。这是本方法在标签不完美时仍然奏效的原因。

### 5.3 逐动作 / 逐通道观察

* 一致性最高的动作（食指伸出、握拳、五指张开）贡献了主要增益；
* 腕部旋前/旋后类动作跨人一致性最低（≈0.10），其伪标签误差最大，
  建议在标定方案中**少用或不用**这些动作；
* 21 路角度中，手指屈伸通道的预测相关（r≈0.8）显著高于腕部通道（r≈0.5）。

## 6. 讨论

### 6.1 为什么这个方案合理

人手的**运动学**（关节角变化规律）由骨骼与肌腱决定，个体差异远小于**肌电解剖映射**
（电极位置、肌肉构型、阻抗）的差异。因此"用别人的运动学 + 本人的肌电"是合理假设，
本实验把它量化了：静态姿态相关 0.787，远高于不同动作（0.025）。

### 6.2 边界条件

* 伪标签的精度上限由**跨人轨迹一致性（0.205）**决定，因此本方法不适合作为
  "高精度角度回放"的唯一标签来源；
* 绝对幅度差异（变异系数 2.5）无法由伪标签修正；**若能借到手套做 1 轮真值标定**，
  预计可显著缩小与 D 组（真标签）的差距——这是最值得做的下一步；
* 本方法依赖"动作分段正确"，即上位机的动作提示与实际执行一致
  （协议中应要求用户看到提示后 0.3 s 内开始动作）。

### 6.3 相关工作方向（写论文时检索用）

* sEMG→运动学回归：CNN / RNN / Transformer 系列；
* 迁移学习与个体校准：少量标定数据 + 微调、对抗域适应；
* 肌电协同（muscle synergy）与手部运动学协同（kinematic synergy）：
  可为本方法的"共享运动学先验"提供理论解释；
* 半监督 / 伪标签学习：本方法是"利用结构先验构造伪标签"的具体实例。

## 7. 局限与下一步

| 局限 | 说明 | 下一步 |
| --- | --- | --- |
| 单目标用户、单基线 | 只在 S2 上验证（基线为 S3） | 扩到 5~8 组"目标×基线"配对实验，报告均值±标准差 |
| 模板未做个体幅度对齐 | 伪标签存在系统性幅度偏差 | 用 1 轮真标签拟合仿射；或用肌电幅度做自监督缩放 |
| 时间对齐仅线性拉伸 | 不同人动作速度不同 | 引入 DTW / 速度归一化 |
| 单模板 | 个体差异未被建模 | 多模板聚类（按手型/动作习惯分组） |
| 未验证真实硬件 | 全部基于公开数据集 | 用自采数据复现同一套四组对照 |

## 8. 复现步骤

```bash
cd 算法/src

# ① 建立模板库（供体受试者：1/4/5/6）
python shared_kinematics.py --subjects 1,4,5,6 --save-template ../outputs/运动学模板_S1S4S5S6.npz

# ②（可选）查看跨人一致性报告
python shared_kinematics.py --subjects 1-8

# ③ 把目标用户（S2）转成自采格式（S03 是基线模型的作者）
python ninapro_to_custom.py --subjects 2 --out-dir ../outputs/自采格式样例

# ④ 生成伪标签（不需要手套）
python make_pseudo_labels.py --template ../outputs/运动学模板_S1S4S5S6.npz \
    --in-dir ../outputs/自采格式样例 --out-dir ../outputs/自采格式样例_伪标签 --subjects 2

# ⑤ 微调（训练用伪标签，评估用真角度）
python finetune.py --base ../plugins/模型权重_连续关节角.npz \
    --data-dir ../outputs/自采格式样例_伪标签 --eval-data-dir ../outputs/自采格式样例 \
    --subjects 2 --epochs 16 --lr 2e-4 --freeze-front --out ../outputs/伪标签迁移_连续关节角.npz

# ⑥ 真标签对照组：把 ⑤ 的 --data-dir 换回真标签目录即可
```

| 文件 | 作用 |
| --- | --- |
| `src/shared_kinematics.py` | 跨人一致性分析 + 模板库导出 |
| `src/make_pseudo_labels.py` | 用模板生成伪标签并报告其质量 |
| `src/ninapro_to_custom.py` | 把公开数据集转成自采格式（做对照实验用） |
| `src/finetune.py` | 个人化微调（支持"训练用伪标签、评估用真标签"） |
| `src/个人化迁移.py` | 一键把上位机采集的数据变成个人模型 |

## 附录 A：术语

| 术语 | 解释 |
| --- | --- |
| 用户迁移（user transfer / personalization） | 把通用模型适配到新用户，使其精度恢复到可用水平 |
| 伪标签（pseudo label） | 不用人工/传感器标注，而由先验（本文为动作模板）生成的替代标签 |
| 运动学模板 | 某动作在人群中平均的关节角轨迹 |
| 仿射校准 | 逐通道线性修正 `y ≈ a·ŷ + b`，用于修正幅度偏小与偏置 |
| R² / r / MAE | 决定系数 / 皮尔逊相关系数 / 平均绝对误差 |

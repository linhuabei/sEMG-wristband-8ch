# Node 御识 · 上位机使用说明

适用于 `节点御识 v260920` 源码版。项目概览、协议和打包方式见 [README.md](README.md)。

> 仓库内的目录和文件名使用英文；界面文案、数据内容和本文档保持中文。

## 一、启动

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 普通启动 | 双击 `start.bat` | 优先用 `.venv` 里的 `pythonw.exe`，没有则用系统 `pythonw` |
| 调试启动 | `start.bat debug` | 保留控制台，能看到 BLE/连接日志 |
| 完整性检查 | `start.bat check` | 等价于 `python run.py --check` |
| 命令行 | `python run.py` | 不经过批处理 |

首次运行如果没有 `.venv`：

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

## 二、界面布局

- **左侧**：设备连接（扫描/连接）+ 三个功能页导航；
- **中间**：当前功能页内容；
- **右侧**：常驻控制栏，分「控制」和「调试」两页，切页面时不会消失。

三个功能页：

| 导航 | 页面 | 用途 |
| --- | --- | --- |
| 01 连接与监视 | `ui/views/monitor_view.py` | 扫描/连接、8 路实时波形、波形录制 |
| 02 数据采集 | `ui/views/data_capture_view.py` | 采集自采数据集（8 通道肌电 + 预留角度通道） |
| 03 用户迁移 | `ui/views/user_transfer_view.py` | ① 标定采集 ② 实时识别与个人化迁移 |

## 三、连接设备

1. 手环上电，确认状态灯亮（广播中为慢呼吸）；
2. 点左侧「扫描」，等待设备列表出现 `Node_1_by_hzx`；
3. 选中设备 → 「连接」；
4. 连接成功后固件自动开始采集，左侧波形开始滚动，顶栏变为「已连接」。

> 当前版本没有「断开」按钮；关闭程序即断开。若连接失败，先确认手环没有被手机或其他电脑占用。

## 四、右侧「控制」栏

| 分组 | 内容 |
| --- | --- |
| 设备状态 | 连接状态、设备名、采样率、接收帧率 |
| 采集（硬件） | 开始采集 / 停止采集、1000 / 2000 Hz 切换 |
| 滤波 | 带通 20–450 Hz、带阻 50 Hz（默认全开） |
| IMU 姿态 | LSM6DSR 3D 方块、横滚/俯仰/航向、零位校准、轮询开关 |
| 录制波形 | 开始/停止录制，文件写入 `recordings/` |
| 自采数据集 | 开始采集 / 停止并保存，文件写入 `captured_data/` |
| 标定采集 | 开始训练 / 停止，文件写入 `training_data/` |

「调试」页包含 GPIO 读写、I2C/SPI 测试、IMU 读取、ADS1298 复位、命令控制台。断线后仍可使用命令台查看日志。

## 五、数据采集页

1. 右侧「控制 → 自采数据集」点「开始采集」（会自动跳到本页）；
2. 让受试者按动作做几组；
3. 点「停止并保存」。

输出目录：`captured_data/capture_YYYYMMDD_HHMMSS/`

- `emg.csv`：`timestamp,ch1..ch8`
- `meta.json`：采样率、通道数、样本数、时长、备注
- `angles.csv`：仅在接入角度源后生成（当前为预留接口）

## 六、用户迁移

### 1. 标定采集

1. 进入「03 用户迁移 → ① 标定采集」；
2. 「测试方案」区域勾选动作、设置每轮次数和时长；
3. 点右侧「标定采集 → 开始训练」，按屏幕提示做动作；
4. 结束后在 `training_data/session_YYYYMMDD_HHMMSS/training_*.csv` 得到带标签数据。

标签约定：`0=休息`、`1=握拳`、`2=十指张开`、`3=OK`、`4=比大拇指`、`5=比耶`、`6=捏合`。

内置模板 `plans/personal_calibration_plan.json` 为 6 动作 × 6 轮 × 3 秒，轮间休息 2 秒。

### 2. 实时识别

1. 进入「03 用户迁移 → ② 实时识别与迁移」；
2. 点「导入算法 .py」选择算法插件；
3. 佩戴设备做动作，卡片显示当前手势/置信度；`TYPE="angles"` 的插件会显示关节角度。

默认的「内置阈值」只会输出握拳/张开/无，仅用于联调，不是正式识别模型。

### 3. 个人化迁移（可选）

1. 按上面完成一轮标定采集；
2. 点「个人化迁移」，选择刚生成的 `session_*` 目录；
3. 程序在该目录生成 `personalize.bat`；
4. 在一台已安装 PyTorch 的电脑上双击运行；
5. 回到本页重新「导入算法 .py」，即可使用该用户的模型。

> 迁移脚本依赖同级的 `算法/src/个人化迁移.py`，本仓库不包含 `算法/` 目录。可用环境变量 `EMG_PYTHON` 指定带 PyTorch 的 Python。

## 七、算法插件

插件是一个普通 `.py` 文件，必须包含：

```python
NAME = "算法名"
TYPE = "gesture"      # 或 "angles"

def predict(ctx):
    f = ctx["features"]   # rms / mav / zc / wl / samples(T, 8)
    return "握拳", 0.92    # TYPE="angles" 时返回角度数组
```

`predict` 约每 50 ms 调用一次。参考 `examples/example_classifier.py`、`examples/example_angles.py`。

## 八、数据目录

| 目录 | 内容 |
| --- | --- |
| `captured_data/` | 自采数据集：`emg.csv`、`meta.json` |
| `training_data/` | 标定采集：`session_*/training_*.csv` |

## 九、常见问题

**扫描不到设备**

- 确认手环已上电、状态灯在呼吸；
- 确认电脑蓝牙已打开，手环没有被手机/其他电脑连接；
- 靠近设备后重新扫描。

**连上但波形不动**

- 看「调试 → 命令控制台」是否有 `EMG_CFG:...`；
- 发 `EMG_START` 手动开始，发 `ADS_DBG` 检查 ADS1298 是否在转换；
- 老固件可能不支持二进制流，需要烧录配套固件。

**波形漂移/满屏**

- 确认右侧「滤波」里的带通和 50 Hz 陷波已勾选；
- 直流阻断始终开启；电极接触不良也会造成大幅漂移。

**识别一直是「无」或「握拳」**

- 默认是 RMS 阈值占位，请导入真实算法插件；
- 检查波形幅值是否过小，必要时调整电极/增益（`ADS_GAIN=12`）。

**个人化迁移提示找不到脚本**

- 需要同级的 `算法/src/个人化迁移.py`；
- 运行的 Python 需要安装 PyTorch，可用 `EMG_PYTHON` 指定解释器。

**exe 双击没反应**

- 用 `start.bat debug` 从源码运行看报错；
- 确认 `resources/` 和 `examples/` 与 exe 的相对位置正确，或重新按 README 打包。
